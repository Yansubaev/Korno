# Календарные периоды вместо скользящего окна

Сводка на главном экране и чипы периода на экране списка активностей считали «неделю» и «месяц» как скользящее окно последних N дней/месяцев, причём каждое место — по-своему (`now - 7 days` на главном, отдельная проверка elapsed-time в списке). Решили: период — это всегда календарные границы (текущая неделя, текущий месяц), а не скользящее окно. Так число совпадает с формулировкой в UI («эта неделя»), не расходится между экранами и не меняется молча в течение дня без начала нового периода.
